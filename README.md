Research objective

Triple-negative breast cancer lacks the receptor targets that guide treatment in other subtypes. The IGF1R/AKT3 axis has been implicated in TNBC in cell-line work, and miR-497 and miR-424 — two members of the miR-15/107 family sharing a common seed sequence — have been reported to regulate these transcripts. To my knowledge, this relationship has not been characterised in primary tumours.

This repository contains the analysis addressing four questions:

	1.	Are IGF1R and AKT3 differentially expressed in TNBC relative to normal breast tissue and to other subtypes?
	2.	Do miR-497 and miR-424 correlate inversely with their hypothesised targets within the TNBC cohort?
	3.	Is the expression of these molecules associated with overall survival?
	4.	What co-expression network and pathways are IGF1R and AKT3 embedded in within TNBC?

Data

All data are publicly available; no patient-identifiable information is used.

Cohort	Data type	Source
TCGA-BRCA	RNA-seq counts, miRNA-seq, clinical	GDC, via TCGAbiolinks
TCGA normal-adjacent	RNA-seq counts	GDC
METABRIC	Expression array, survival	cBioPortal
GEO validation cohort	Expression array, survival	GEO

TNBC is defined in two independent ways — by IHC receptor status (ER−/PR−/HER2−) and by PAM50 basal-like subtype — and all main results are reported under both definitions.

Reproducibility

Run scripts/00_setup.R first; it installs dependencies and writes session_info.txt recording all package versions. Raw and intermediate data files are excluded from version control (see .gitignore) and can be regenerated by running the pipeline in order.

Requires R ≥ 4.3 with TCGAbiolinks, DESeq2, limma, survival, survminer, clusterProfiler, org.Hs.eg.db, tidyverse and ggpubr.
